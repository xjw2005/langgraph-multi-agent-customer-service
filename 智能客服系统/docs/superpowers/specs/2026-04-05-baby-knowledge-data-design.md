# 母婴常识数据批量导入设计方案

## 项目概述

为智能客服系统的RAG知识问答模块添加50条结构化的母婴常识数据，采用快速批量导入方式，确保与现有Chroma向量数据库系统完美集成。

## 需求分析

### 核心需求
- 添加50条母婴专业常识数据
- 支持RAG检索和问答功能
- 覆盖0-24个月各发育阶段
- 提供权威、实用的育儿指导

### 技术约束
- 必须兼容现有BabyKnowledgeVectorStore系统
- 数据格式需符合Chroma向量数据库要求
- 支持按领域、月龄、难度等维度检索

## 系统架构

### 现有系统组件
- **BabyKnowledgeVectorStore**: Chroma向量存储管理
- **ProfessionalQAAgent**: 专业问答处理Agent
- **BabyKnowledgeRetriever**: 知识检索器

### 新增组件
- **BabyKnowledgeGenerator**: 母婴常识数据生成器
- **KnowledgeImporter**: 批量数据导入工具
- **ValidationTester**: 数据验证测试工具

## 数据设计

### 数据结构
```python
{
    "content": "问答形式的常识内容",
    "source": "权威来源机构",
    "title": "常识标题",
    "domain": "知识领域",
    "age_range": "适用月龄范围",
    "authority": "权威级别",
    "keywords": ["关键词列表"],
    "difficulty": "难度等级",
    "content_type": "内容类型",
    "last_updated": "更新时间"
}
```

### 领域分布
- **baby_care（日常护理）**: 12条
  - 洗澡护理、换尿布、皮肤护理、睡眠管理等
- **nutrition（营养喂养）**: 12条
  - 母乳喂养、奶粉选择、辅食添加、营养搭配等
- **development（发育成长）**: 10条
  - 运动发育、语言发展、认知能力、社交技能等
- **safety（安全防护）**: 8条
  - 意外预防、急救知识、环境安全、用品安全等
- **products（用品选择）**: 8条
  - 选购指南、使用方法、品质识别、性价比分析等

### 月龄覆盖
- **0-1个月（新生儿）**: 10条
- **1-6个月（婴儿期）**: 15条
- **6-12个月（活动期）**: 15条
- **12-24个月（幼儿期）**: 10条

## 实施方案

### 第一阶段：数据生成
1. 创建BabyKnowledgeGenerator类
2. 定义常识模板和生成规则
3. 按领域批量生成结构化数据
4. 确保内容专业性和实用性

### 第二阶段：数据导入
1. 创建KnowledgeImporter工具
2. 批量导入到Chroma向量数据库
3. 建立领域索引和元数据映射
4. 验证数据完整性

### 第三阶段：测试验证
1. 创建ValidationTester测试套件
2. 验证RAG检索功能
3. 测试问答准确性
4. 性能基准测试

## 技术实现

### 核心文件
- `data/baby_knowledge_generator.py`: 数据生成器
- `init_baby_knowledge.py`: 初始化脚本
- `test_knowledge_system.py`: 测试验证脚本

### 集成点
- 与现有`rag/vector_store.py`集成
- 兼容`agents/qa_agent.py`的检索逻辑
- 支持`api_server.py`的知识搜索接口
